# نظام الرعد — Charge / Release

نظام الرعد هو هوية القتال الأساسية في ALSAEQA، لكنه لا يلغي السلاح أو القتال القريب.

## دورة الهجوم
- شحنة سريعة: إطلاق فوري بطاقة منخفضة.
- شحنة متوسطة: ضرر ومدى أفضل مع مخاطرة أكبر.
- شحنة كاملة: أقصى قوة، لكن زمن التعرض للخطر أطول.
- يمكن ربط الإطلاق بضربة سلاح أو تفاعل بيئي لصناعة هجمات مركبة.

## فلسفة التصميم
الرعد يجب أن يخدم القتال والاستكشاف معًا. القوة ليست زر ضرر فقط؛ يمكنها تشغيل آثار قديمة، إضاءة المنجم، شحن آليات، كسر حواجز محددة، وكشف فرص تفاعل.

## التوازن
- لا يوجد انتظار إجباري للعاصفة حتى يستطيع اللاعب التقدم.
- الشحن الكامل قوي لكنه ليس الحل الوحيد.
- بعض الأعداء لديهم مقاومات ونقاط ضعف، لا مناعة مطلقة بشكل متكرر.
- البيئة يمكن أن تضخم قيمة الرعد دون أن تجعل اللاعب عاجزًا بدونه.

## العاصفة الديناميكية
العاصفة حدث عالمي اختياري:
- تزيد كفاءة بعض قدرات الرعد مؤقتًا.
- تفعّل تفاعلات نادرة.
- قد تكشف طرقًا أو أعداء أو أحداثًا غير متاحة في الطقس الهادئ.
- الزعماء والأعداء يمكن أن يستفيدوا منها أيضًا.
- لا تكون شرطًا دائمًا لإنهاء المرحلة.

## التنفيذ
الطبقة الأولى مكوّن C++ مستقل: `UALSAEQAThunderChargeComponent`.
يمكن لاحقًا ربطه باللاعب، الضرر، المؤثرات، الصوت، البيئة، الطقس، والـ Blueprint دون تغيير قاعدة الشحن الأساسية.
