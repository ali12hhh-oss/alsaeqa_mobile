# ALSAEQA Character Variant Production

This is the production checklist for turning licensed base meshes into characters unique to ALSAEQA.

## Hero
1. Start from a male humanoid base with real topology/rig.
2. Use a distinct hair silhouette.
3. Combine survivor/miner clothing with asymmetric shoulder/forearm protection.
4. Add the signature thunder-forged blade as a real weapon mesh.
5. Keep the silhouette readable without emissive effects.
6. Produce four saved variants: Survivor, Awakened Heir, Storm Warrior, Thunder Giant Descendant.

## Companion
1. Use a separate female base and different hairstyle.
2. Use layered travel/light armor parts rather than the Hero outfit.
3. Add a permanent family-symbol accessory.
4. Give her a distinct weapon silhouette.
5. Produce normal, captured/damaged, and rescued/restored variants.

## Enemy factions
Create at least three silhouette/equipment combinations for each faction: Mine Overseer, Tyrant Soldier, Storm Hunter, Fortress Elite, Desert Raider, Ice Guard. Recolor-only variants are rejected.

## Production rules
- Preserve the source armature and weights when possible.
- Use real modular meshes and real materials.
- Prefer material instances over destructive recoloring.
- Never add primitive spheres/cylinders to fake anatomy.
- Every final character must be recognizable from a small thumbnail by silhouette and equipment.
- Export optimized GLB/FBX for Unreal 5.8 and keep the source Blender file outside the game repository when its license/source terms require it.
