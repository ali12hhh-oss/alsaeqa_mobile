# الصاعقة موبايل — ALSAEQA Mobile

المشروع الرسمي لتحويل لعبة **الصاعقة** إلى لعبة Android Mobile ثلاثية الأبعاد، مع الحفاظ على الهوية والقصة والمراحل والمشاهد السينمائية والقتالية وتطور البطل والرفيقة والقدرات والمركوبات.

## الحالة
- البنية Mobile-first موجودة داخل `mobile/`.
- سجل المراحل 1–70 موجود.
- أساس الحركة والكاميرا والتحكم اللمسي وHUD موجود.
- أساس Stage 1 موجود.
- مدير السينمائيات موجود.
- خط GitHub Actions للتنزيل والتحويل والتحقق وتصدير APK موجود.
- طبقة الأصول الحقيقية القابلة لإعادة التحويل موجودة.

## الأصول الحقيقية
المصدر المعتمد هو Releases في `ali12hhh-oss/alsaeqa`.

الحزم الثلاث المعتمدة:
- `ALSAEQA_REAL_ASSETS.zip`
- `ALSAEQA_EXTRA_MONSTERS.zip.zip`
- `ALSAEQA_EXTRA_ULTIMATE_MODULAR_RUINS.zip.zip`

لا نضع الحزم الضخمة داخل تاريخ Git. يتم تنزيلها في GitHub Actions والتحقق من SHA-256 ثم استخراجها وتحويل الأصول المطلوبة للموبايل.

## قابلية تعديل الأصول
التصميم المعتمد:

`Logical Asset ID → Source Asset → Converted Mobile Asset → Scene/Character/Weapon Binding`

الملفات المسؤولة:
- `mobile/assets/asset_manifest.json`
- `Tools/Assets/sync_real_assets.py`
- `Tools/Assets/blender_convert.py`
- `mobile/assets/README.md`

بهذا يمكن تعديل أو استبدال المصدر الحقيقي ثم إعادة التحويل دون تغيير منطق اللعبة عند الحفاظ على الـlogical ID.

**ممنوع اعتماد primitive/blockout كرسومات نهائية.** أي blockout موجود هو مؤقت ويجب استبداله بالأصل الحقيقي.

## ما لم يكتمل
- ربط كل أصل حقيقي محدد بالمشهد النهائي.
- تحسين كل نموذج/Texture/Material/LOD للموبايل.
- إدخال كل Animation وربطها بالشخصيات.
- ربط الشخصيات والأسلحة والوحوش والمركوبات الحقيقية.
- Stage 1 بصرياً وسينمائياً بالكامل.
- VFX الرعد، خصوصاً تأثير سلاح الرعد.
- الصوت والموسيقى النهائية.
- AI الكامل، الحوار، المهام، الأحداث، الحفظ الكامل، والتحسين النهائي للأجهزة.
- اختبار APK فعلي.

## وثيقة التسليم الرئيسية
**`Docs/الصاعقة_موبايل_وثيقة_المشروع.md`** هي المرجع الجديد لمن يكمل المشروع، وتحتوي على الحالة والإنجازات والنواقص وقواعد الأصول وترتيب العمل.

## قاعدة الاستمرارية
هذا هو مشروع **الصاعقة موبايل** الواحد. لا V1/V2/V3 ولا إعادة تنفيذ لما اكتمل. قبل أي تعديل اقرأ وثيقة المشروع والاستمرارية، افحص الحالة الفعلية، ثم أكمل أعلى بند غير مكتمل.
